# Scoped Cloudflare Images fixture diagnostic

`worker.ts` is a standalone module entrypoint for one temporary Worker. It is not linked from Ante application routes. The deployment controller must use the reviewed temporary Worker name and the `IMAGES` binding (`type: images`, `name: IMAGES`), supply a dedicated random 64-hex-character `ANTE_IMAGES_PROBE_TOKEN` as secret text, and supply `ANTE_IMAGES_PROBE_EXPIRES_AT` as UTC plain text. No credential value belongs in this directory. Only `POST /probe` with `x-ante-images-probe-token` and one exact MIME/body pair from `manifest.json` is accepted.

The handler checks expiry and token before reading a body or invoking Images. It limits streamed input and output to 10 MiB and applies a ten-second wall deadline to body reads and awaited binding work. It computes the input SHA-256 before calling `IMAGES.info`, rejects unexpected dimensions/format/size, then calls `IMAGES.input` with raw bytes. The transform uses `fit: "scale-down"`, `metadata: "none"`, landscape 1920×1080 or portrait 1080×1920 bounds, then JPEG at quality 85. It bounds, inspects, and hashes the encoded output and returns JSON metadata only. All responses have `private, no-store` and fixed error codes; provider text, secrets and bodies are never logged or returned. There is no source URL, external fetch, Storage, database, or payment call.

The four earlier fixtures are all opaque, including both PNGs. The manifest documents their known metadata; this diagnostic selects JPEG for all four. It does not establish transparent-PNG handling, comprehensive still-image/animation or HEIC auxiliary validation, metadata stripping, color/HDR handling, privacy of any production route, or resource acceptance. `anim: false` requests a still output but is not an animation rejection rule. A handler deadline cannot forcibly terminate Image service work already dispatched. These remain production acceptance work after the provider feasibility result.

The binding calls and option names follow [Cloudflare's Images binding guide](https://developers.cloudflare.com/images/optimization/binding/) and [transform feature reference](https://developers.cloudflare.com/images/optimization/features/). The binding's documented 20 MB input ceiling exceeds this probe's 10 MiB cap; supported format listings do not establish that the exact HEIC will succeed. Local tests replace the external Images service and therefore verify orchestration and admission only.
